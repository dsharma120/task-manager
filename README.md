### Responsive Task Manager Web Application

A clean, interactive frontend Task Manager application built using vanilla web technologies. This project demonstrates responsive user interface design, dynamic DOM manipulation, and browser-based data persistence. 

Live Demo: [Insert Your GitHub Pages Link Here] 

### Key Features

* **Full CRUD Functionality:** Seamlessly add, view, toggle, and delete individual daily tasks.
* **Persistent Data Storage:** Integrates with the browser's localStorage API to retain user tasks across session refreshes.
* **Modern Responsive UI:** Designed with a mobile-first approach using clean CSS layouts that automatically scale to mobile, tablet, and desktop viewports.
* **Optimized UX Logic:** Features intuitive keyboard support, allowing users to submit inputs using the "Enter" key instantly.

### Technologies Used

* **HTML5:** Semantic document scaffolding.
* **CSS3:** Custom layouts, transition animations, and modern typography properties.
* **JavaScript (ES6+):** Event listener handling, dynamic array manipulation, and asynchronous browser storage mechanics.
